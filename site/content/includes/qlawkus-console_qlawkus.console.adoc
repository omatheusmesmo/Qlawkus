[.description]
--
How much of the agent's tool activity the chat page shows while a turn runs. `off` shows only a "N tools, Xs" summary line, `status` shows each tool's name and duration, `preview` adds the first 40 characters of its arguments, and `verbose` adds the arguments (up to 300 characters) in a collapsible detail. Tool results are never shown. The messaging channels are meant to take the same four names.

[.description]
--
Browser-reachable base URL of Grafana (for example `http://localhost:3000`), not the in-network address the agent uses. When set, the overview shows an Observability card linking the Qlawkus dashboard and Grafana Explore on Prometheus, Tempo and Loki, which are all reached through Grafana. Only a plain http or https URL is accepted: anything else is ignored with a warning. When unset, the console shows no links.
