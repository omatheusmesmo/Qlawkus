[.description]
--
Browser-reachable base URL of Grafana (for example `http://localhost:3000`), not the in-network address the agent uses. When set, the overview shows an Observability card linking the Qlawkus dashboard and Grafana Explore on Prometheus, Tempo and Loki, which are all reached through Grafana. Only a plain http or https URL is accepted: anything else is ignored with a warning. When unset, the console shows no links.
