[.description]
--
The cognition persistence backend. `markdown` keeps curated content in files and needs no database; `pgvector` puts embeddings in Postgres; `hybrid` uses files as the source of truth mirrored into pgvector.

The value only selects among backends that are actually on the classpath. The markdown stores are the `@DefaultBean`, so a build without the `cognition-pgvector` extension runs on files whatever this says. With the extension present and nothing set, a configured `quarkus.datasource.jdbc.url` means `pgvector` and its absence means `markdown`, which also switches the datasource, Hibernate ORM and Flyway off. A value set here wins over both. The declared default is therefore `markdown` only when no datasource URL is configured.

Allowed values, case-insensitive: `markdown`, `pgvector`, `hybrid`. Any other value fails the boot with a configuration error.
