The provider and key the agent talks to, for chat and for memory embeddings. Saved to the keystore; applies on the next restart.

2. Storage {currentBackend}

Where memory lives. Files need nothing; Postgres (with pgvector) scales and survives a rebuild. Saved to the keystore; applies on the next restart.

3. Capabilities

What gets compiled into the agent. Staged as a manifest; applies on rebuild + redeploy.
